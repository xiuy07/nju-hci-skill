# 南京大学人机交互系统课程 Skill

**整理自南京大学人机交互系统课程。** 非官方整理，不代表南京大学或任课教师意见。仓库不附原 PDF。

将课程知识整理为 Codex 按需读取的 `nju-hci` skill，兼顾复习和实际交互分析。

## 使用场景

| 场景 | 示例 |
| --- | --- |
| 课程复习 | 讲解两个隔阂，比较认知走查与启发式评估 |
| 需求与原型 | 人物角色、场景、HTA、需求验收、原型选择 |
| 界面评审 | 找具体问题，给用户影响、修改与验证办法 |
| 用户研究 | 观察、访谈、问卷、DECIDE 与比较实验计划 |
| 预测建模 | GOMS/KLM/Fitts 教学计算与方案比较 |

适用于本科 HCI 学习、课程项目和产品设计初步分析。专家推断不能当真实用户测试；不替代正式统计分析、无障碍认证或行业标准。纯审美创作和普通前端编码无需专门调用。

## 安装

将 `skills/nju-hci` 整个目录复制到 Codex 的 skills 目录，保持 `SKILL.md`、`agents/`、`references/` 的相对结构：

```text
~/.codex/skills/nju-hci/
```

若设置 `CODEX_HOME`，使用其下的 `skills/nju-hci`。Windows 默认通常为用户目录下的 `.codex\skills\nju-hci`。安装后下一轮对话可用；客户端未刷新时重新打开聊天或重启 Codex。

也可在 Codex 请求：

```text
使用 skill-installer 从 Finn-307/nju-hci-skill 安装 skills/nju-hci。
```

私有仓库需当前环境有读取权限。本技能包无额外运行时依赖和执行脚本，计算或检查实际界面时使用环境已有工具。

## 调用示例

```text
使用 $nju-hci，比较组内与组间设计，给一道自拟练习题。
使用 $nju-hci，评审报名页面，区分截图事实与待验证风险。
使用 $nju-hci，为图书预约系统制定 DECIDE 测试计划。
使用 $nju-hci，按课程常数计算 M+9K，并说明起始状态和局限。
```

默认允许自动匹配相关任务，不会为无关工作启动整套设计流程。

入口为 [SKILL.md](skills/nju-hci/SKILL.md)。六份参考材料覆盖 12 章与方法梳理，保留页码索引。见[来源、范围与校订](skills/nju-hci/references/provenance.md)，了解人数经验、记忆容量、公式与研究分类的适用边界。新增案例为自拟，未对原课程资料声明开源许可。
